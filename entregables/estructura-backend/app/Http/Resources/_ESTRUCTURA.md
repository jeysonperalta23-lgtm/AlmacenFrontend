# Respuestas JSON

Crear `EstanteResource`, `ModuloResource`, `ExpedienteResource` y `PaginaResource`
al implementar sus consultas. Seleccionar explícitamente los campos públicos.

Las listas usarán `data` y metadatos de paginación cuando corresponda.
No devolver contraseñas, credenciales móviles, hashes ni rutas privadas del disco.
