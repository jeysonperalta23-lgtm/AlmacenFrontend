# Comprobaciones comunes

Sanctum ya está instalado y el arranque existente habilita la API con estado.
Esto todavía no significa que exista un flujo de login o permisos documentales.

Implementar la comprobación de usuario activo al construir acceso. La validación
de credenciales móviles corresponde a una etapa posterior de digitalización.
Las autorizaciones por área y recurso se resuelven en Policies.
